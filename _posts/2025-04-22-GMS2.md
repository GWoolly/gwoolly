# Hit - A collision library for GameMaker
{% columns %}
{% column %}
I created this lightweight code library as part of the annual Cookbook jam in which members of GameMaker engine's community create tutorials and build new opensource code libraries, tools and assets that empower developers.

Having used Unreal Engine professionally for a while, I noticed how GameMaker had frustratingly always lacked a simple to implement and easily customisable collision system.
The aim of this code library was to introduce a robust and modular collision system that required minimal maintenance and coding from the user, which added enhanced features to the existing object collisions and introduced a fully customisable tile collision system to improve the level design experience.

**<u>Features:</u>**
- Simple to implement for less time coding collision and more time creating.
- Modular and scalable to meet all project requirements.
- Custom collision callbacks.
- Delta timing for perfect collisions every game frame.
- Custom tile collision data.
- Moving tile collisions
